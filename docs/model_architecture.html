1. Architecture Overview

RGB (3×1008²) → Patch Embed → [MMAdapterPromptBlock ×32] → Pyramid4Scale → MFNetDecoder → 5-class logits
DSM (1×1008²) → DSMTokenEncoder → dsm_tokens (63²×1024) │
DSM (1×1008²) → Sobel+Laplacian → PromptEncoder → prompt_tokens (63²×1024)

DSM 和 Prompt token 通过共享的 state dict 注入每一层的 MMAdapterPromptBlock。

2. Inside MMAdapterPromptBlock

Attention Stage

RGB x → frozen attn → attn_x + rgb_attn_adapter
DSM y → frozen attn → attn_y + dsm_attn_adapter
RGB 和 DSM 共享同一个 frozen attention 权重

MLP Stage (Fusion)

x → frozen MLP → mlp_x + rgb_mlp_adapter + dsm_mlp_adapter + prompt_mlp_adapter
Gate: softmax(w_rgb, w_dsm, w_prompt)
3 分支通过 softmax gate 自动选择权重，避免 multi-sigmoid 叠加
